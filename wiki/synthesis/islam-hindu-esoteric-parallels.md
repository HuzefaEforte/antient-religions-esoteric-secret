# Islam ↔ Hindu esoteric parallels

The organizing comparison of [[S0001]]: a claimed one-to-one correspondence between Islamic and
Hindu esotericism, converging on [[non-duality]]. Recorded here as a **map of the source's
argument** — the parallels are its interpretive synthesis (`esoteric`/`llm-generated`), not an
established scholarly equivalence. For the caution, see [[perennialism-and-modern-overlay]].

## The core mapping

| Layer / idea | Islamic esotericism | Hindu esotericism |
|---|---|---|
| Outer ritual law | Shariat | Karma Kanda |
| Decoding tool | **[[tawil|Ta'wil]]** (symbolic) | Nirukta / Paroksha (indirect); *Gupta Vidya* |
| Inner knowledge corpus | the *batin*; Sufi/[[tayyibi-ismailism|Ismaili]] teaching | the **[[upanishads]]** (Jnana Kanda) |
| Ultimate reality | **[[wahdat-al-wujud|Haqiqat / al-Haqq]]** | **[[atman-brahman|Satya / Brahman]]** |
| The one truth | **[[wahdat-al-wujud]]** (Unity of Being) | **[[advaita-vedanta]]** (Aham Brahmasmi) |
| Ego-dissolution | **[[fana|Fana]]** (annihilation) | Neti-Neti; Moksha |
| The illusion | Dunya / Khalq; **Ghaflah** (heedlessness) | **[[maya|Maya]]**; Avidya |
| The witness | the heart's witness; still center | **[[four-states-of-consciousness|Turiya]]** / Sakshi |
| Timeless present | *Waqt* | *Sat* — see [[the-observer]] |
| Cosmic origin | "**Hidden Treasure**" hadith; [[emanation|Sudur/Fayd]] | Nasadiya Sukta; *Kama/Spanda* (primal ripple) |

## The shared analogies

[[S0001]] argues both traditions reach for the same images to convey oneness:
- **Wave ↔ Ocean** — the wave is already the ocean.
- **Cinema screen** — you are the untouched screen, not the movie ([[the-observer]]).
- **Gold** — crown/map/ring are one substance ([[atman-brahman]]).
- **Steam / water / ice** — Source, [[emanation|Intellects]], and matter as one fabric at
  different densities.

## Wider frame

The source folds in **[[hermeticism]]** ("The All is Mind"), **[[emanation|Neoplatonic emanation]]**
(via [[plotinus]] → [[al-farabi]] → [[ibn-sina]]), and the [[tayyibi-ismailism|Ismaili]]
[[drama-in-heaven]] as further witnesses to the same "One → many → return" architecture — the
**"Perennial Philosophy"** claim examined in [[perennialism-and-modern-overlay]].
